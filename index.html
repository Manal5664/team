Tags ki Tafseel:
Is table ko banane mein sab se pehle <table> tag use hua hai jo pure table ka dhancha (structure) banata hai. <thead> table ka sar ya heading wala hissa hota hai, jabke <tbody> mein asli data hota hai. <tr> ka matlab hai 'Table Row', jo ek nayi line shuru karta hai. <th> heading ke liye hota hai aur <td> normal cells ke liye. Ab baat karte hain attributes ki: colspan tab use hota hai jab aap ek box (cell) ko horizontally do ya do se zyada columns ke barabar phailana chahte hain. Aur rowspan tab use hota hai jab aap ek cell ko vertically (uupar se neeche) do ya do se zyada rows ki jagah dena chahte hain. Aakhir mein <p> tag ye paragraph likhne ke liye use kiya gaya hai.
